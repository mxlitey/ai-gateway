AI Gateway 绿色版
=================

启动方式
--------
双击 ai-gateway-v<版本号>.exe（如 ai-gateway-v1.2.1.exe）：打开桌面窗口，没有黑窗口
  - 设置运行端口（改完点「启动 / 重启」生效）
  - 启动 / 停止网关
  - 查看插件列表、添加插件（选目录）、删除插件、重新扫描
  - 一键打开管理面板
关闭窗口不会退出网关：窗口会最小化到系统托盘继续在后台运行。
  左键单击托盘图标可重新打开窗口；右键托盘图标 →「退出」才停止网关。

管理面板
--------
http://127.0.0.1:8787 （默认端口，可在桌面窗口里修改）
首次打开会让设置管理员密码。

端口说明
--------
- 网关自身：8787（桌面窗口可改）
- 插件端口：由插件自己在 plugin.json 里指定（内置的 TRAE 用 20727、WorkBuddy 用 20800）
  被其他程序占用时会在桌面窗口里报错，改一个端口即可

目录说明
--------
data/      数据库与日志（ai-gateway.db、logs/），请勿删除
plugins/   插件目录；可在桌面窗口里增删，也可手动放目录后点「重新扫描」
mcp/       本地 MCP 服务器目录；每个子目录一个服务（放 mcp.json 与 Python 入口），
           网关启动时自动登记到「MCP 服务器」页，删除目录后重启即移除
           安装包只建这个空目录，不内置示例；可参考仓库 examples/mcp/ 下的两个示例

本地 MCP 服务器
---------------
mcp\ 目录默认为空。把自己的 Python MCP 服务器整个目录放进来即可（每个子目录一个服务），
网关启动时自动分配 127.0.0.1 端口、自动装依赖、崩溃自动重启。
客户端只连网关的 MCP 聚合入口，不会看到本地服务器的端口；可在「API 密钥」里
把某把密钥的 MCP 权限设为「全部 / 仅勾选 / 禁用」，按服务器粒度授权。
完整开发规范见仓库 docs/local-mcp-spec.md。

管理 MCP（可选）
----------------
「设置 → 管理 MCP」可以把网关自身的管理能力（用量、渠道、插件、MCP 上游、上游诊断、
签发密钥等）暴露成一个独立 MCP 服务器（POST /admin/mcp），供 AI 客户端查询与操作。
默认关闭；开启时自动生成管理令牌（amcp_ 开头，只显示一次），并可单独关闭写操作。
它与「MCP 服务器」页聚合的上游工具互不影响。

内置插件
--------
plugins\ 下自带两个现成的插件（都是 Python 源码），用法一样：打开控制台接入账号，
再到「渠道管理」获取模型。examples\ 里还有更多插件源码，需要时复制到 plugins\ 即可。

WorkBuddy（CodeBuddy，端口 20800）
  1. 管理面板 →「插件」→ 打开它的「控制台」
  2. 用「从本机桌面端导入」读取本机已登录的账号，
     或用「OAuth 授权登录（国内站 / 国际站）」接入；之后额度、签到都在这里看
  3. 到「渠道管理」编辑 WorkBuddy 渠道 →「获取上游模型」→ 勾选要用的模型

TRAE（端口 20727）
  1. 管理面板 →「插件」→ 打开它的「控制台」
  2. 点「登录 TRAE 账号」，在浏览器里完成授权（回调会自动捕获）；
     之后额度、签到都在这里看
  3. 到「渠道管理」编辑 TRAE 渠道 →「获取上游模型」→ 勾选要用的模型

模型出现在「模型路由」页后，把模型名填到客户端即可。

客户端接入
----------
API Base URL : http://127.0.0.1:8787/v1
API Key      : 在管理面板「API 密钥」页生成（列表里可随时复制）
Model        : 在「模型路由」页可见的公开模型名

MCP 客户端（Claude Desktop / Cursor / Cline 等）填这段配置：
{
  "mcpServers": {
    "mcp-hub": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:8787/mcp",
      "headers": {
        "Authorization": "Bearer sk-你的密钥"
      }
    }
  }
}

安全提示
--------
默认仅监听本机回环地址；改为对外监听前请确认网络环境安全。
插件凭据只存在本地磁盘，请勿提交到代码仓库或分享给他人。
本工具仅用于调用你本人账号的正当额度，请遵守各上游服务条款。
