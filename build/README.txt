AI Gateway 绿色版
=================

启动方式
--------
双击 ai-gateway.exe：打开桌面窗口，没有黑窗口
  - 设置运行端口（改完点「启动 / 重启」生效）
  - 启动 / 停止网关
  - 查看插件列表、添加插件（选目录）、删除插件、重新扫描
  - 一键打开管理面板
关闭窗口不会退出网关：窗口会最小化到系统托盘继续在后台运行。
  左键单击托盘图标可重新打开窗口；右键托盘图标 →「退出」才停止网关。

管理面板
--------
http://127.0.0.1:8787 （默认端口，可在桌面窗口里修改）
首次打开会让设置管理员密码。

端口说明
--------
- 网关自身：8787（桌面窗口可改）
- 插件端口：由插件自己在 plugin.json 里指定（内置的 TRAE 用 20727、WorkBuddy 用 20800、
  ModelScope 用 20810、Kilo 用 20812、Cline 用 20815、MiniMax Code 用 20816、
  Loomy 用 20817、LobsterAI 用 20818、Gemini 用 20819）
  被其他程序占用时会在桌面窗口里报错，改一个端口即可

目录说明
--------
data/      数据库与日志（ai-gateway.db、logs/），请勿删除
plugins/   插件目录；可在桌面窗口里增删，也可手动放目录后点「重新扫描」

内置插件
--------
plugins\ 下自带九个现成的插件（都是 Python 源码），用法一样：打开控制台接入账号，
再到「渠道管理」获取模型。

WorkBuddy（CodeBuddy，端口 20800）
  1. 管理面板 →「插件」→ 打开它的「控制台」
  2. 用「从本机桌面端导入」读取本机已登录的账号，
     或用「OAuth 授权登录（国内站 / 国际站）」接入；之后额度、签到都在这里看
  3. 到「渠道管理」编辑 WorkBuddy 渠道 →「获取上游模型」→ 勾选要用的模型

TRAE（端口 20727）
  1. 管理面板 →「插件」→ 打开它的「控制台」
  2. 点「登录 TRAE 账号」，在浏览器里完成授权（回调会自动捕获）；
     之后额度、签到都在这里看
  3. 到「渠道管理」编辑 TRAE 渠道 →「获取上游模型」→ 勾选要用的模型

ModelScope 魔搭（端口 20810）
  1. 管理面板 →「插件」→ ModelScope 的「控制台」
  2. 点「OAuth 授权登录」在浏览器里授权；或用「粘贴令牌登录」填魔搭访问令牌
     （令牌页：https://modelscope.cn/my/myaccesstoken）
  3. 想吃每日魔粒：该账号需要 Web 会话 Cookie。
     OAuth 登录未必能采到 Cookie，可用「补充 Web 会话 Cookie」粘贴一次浏览器 Cookie；
     不贴也能正常对话，签到会如实提示「没有 Web 会话 Cookie」
  4. 到「渠道管理」编辑 ModelScope 渠道 →「获取上游模型」→ 勾选要用的模型

Kilo 免费池（端口 20812）
  1. 不需要账号、不需要 Key：上游是 Kilo AI 的公共免费模型池
  2. 到「渠道管理」编辑「Kilo 免费池」→「获取上游模型」→ 勾选免费模型
  3. 只有上游标记 isFree 的模型可用；付费模型会返回
     「该模型不在 Kilo 免费池里」的 400，不会消耗任何凭据
  4. 免费池的上游声明 prompt 可能被记录用于改进服务，请勿发送敏感内容

Cline（端口 20815）
  1. 控制台 → 点「Cline 设备码登录」，浏览器里确认用户码，面板会自动等到登录完成
     （也可以「粘贴访问令牌」，填已有的 workos: 令牌）
  2. 「刷新额度」可查余额；之后到「渠道管理」→「获取上游模型」→ 勾选模型

MiniMax Code（端口 20816）
  1. 控制台 → 点「MiniMax Code 设备码登录」，浏览器里确认用户码
  2. 「签到」领每日积分，「刷新额度」看积分；之后到「渠道管理」→「获取上游模型」

Loomy 讯飞（端口 20817）
  1. 控制台 →「① 发送短信验证码」填手机号
  2. 收到短信后点「② 提交短信验证码」，填同一个手机号与验证码
  3. 之后可「签到」初始化每日额度、「刷新额度」看积分

LobsterAI 有道（端口 20818）
  1. 控制台 →「LobsterAI 授权登录」，浏览器里完成授权后自动入库
  2. 「刷新额度」查余额；之后到「渠道管理」→「获取上游模型」

Gemini Code Assist（端口 20819）
  1. 控制台 →「粘贴 Google refresh_token」：Google 只接受本机回环回调，
     插件不自建额外端口，故这里用粘贴方式接入
  2. 「刷新额度」查剩余 tokens；模型名带思考档位后缀（-low / -medium / -high / -tiered）

模型出现在「模型路由」页后，把模型名填到客户端即可。

客户端接入
----------
API Base URL : http://127.0.0.1:8787/v1
API Key      : 在管理面板「API 密钥」页生成（列表里可随时复制）
Model        : 在「模型路由」页可见的公开模型名

安全提示
--------
默认仅监听本机回环地址；改为对外监听前请确认网络环境安全。
插件凭据只存在本地磁盘，请勿提交到代码仓库或分享给他人。
本工具仅用于调用你本人账号的正当额度，请遵守各上游服务条款。
