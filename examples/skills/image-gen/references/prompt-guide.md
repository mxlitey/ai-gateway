# 生图提示词指南

## 描述最终画面

用具体、可见的词写结果，不要写抽象目标。

- **插画/动漫/手绘**：写清媒介与完成度——线宽、上色方式、笔刷或纸面质感、配色；
  要柔和光线、克制饱和度、背景细节丰富。
- **写实**：要自然饱和度与中性白平衡；除非用户要浓烈色调。
- **人物**：重要人脸给近景或中景；远景人物给背影或侧脸。写清肤色自然均匀，
  表情用可见特征描述（抬眉、浅笑）。
- **海报/分镜**：给出层级、视觉焦点、留白。多格时逐格写镜头大小、主体、动作，
  并重复同一段风格描述。
- **数据与文字**：把用户给的名称、数字、步骤原样写进提示词；图表要给出每个数值与轴范围。
- **位置**：用「左上、前景」这类相对说法，不用东南西北。

## 一次出多图

一个请求返回整张拼图（3×3 分镜、步骤条、多视图等），在提示词里描述整体版式与每一格内容；
内容太多时按章节拆成多次请求。

## 参考图分工

工具参数没有 role 字段，**角色只能写在提示词里**，并和图序对应。

| 用途 | 提示词写法 |
| --- | --- |
| 人物/角色 | 用「图 1 里的角色」，要求保持身份；只在用户点名时才补充外貌 |
| 产品 | 保持外形、比例、质感、Logo 与可读文字；换视角要提示模型推断未拍到的侧面 |
| 风格 | 「取图 2 的配色/线稿/明暗」，主体与文案另取来源 |
| 姿态/构图 | 指明沿用哪个部分：手势、版式、机位 |
| 合成 | 底图放第一张，新增元素给位置，并要求匹配比例、透视、光照与接触阴影 |
| 试穿 | 人物第一张、衣物第二张；保持身份、体型、姿态，迁移剪裁与图案 |
| 草图渲染 | 沿用版式、比例、透视；把构造线与手写批注当指引 |
| 场景/光线 | 指明场景图里哪些保留（房间形状、窗、固定家具）、哪些改变（时间、陈设） |
| 特征混合 | 逐个特征对应到具体图号，如「耳朵取图 1、花纹取图 3」 |

**改图**要把「保持不变」写清楚：人物身份、面部、姿态；产品形状、logo、数量；场景几何与机位；
白平衡与色温。用户没说清楚改哪里时，先问，不要猜。

图上画了圈、箭头、手写批注时，让模型按标记执行，并把标记从结果里去掉（除非用户要保留）。

## 常见组合

```text
# 文生图
3D 渲染的雨夜书店，海军蓝与琥珀色配色，暖黄灯光从橱窗透出

# 参考图改背景
以图 1 为基础，把背景换成纯白影棚背景（#FFFFFF），
保留产品本身、比例、logo 与文字，底部加柔和自然阴影，不留原背景残色

# 多图合成
把图 1、图 2、图 3 中的三个人放到图 4 的咖啡馆同一张桌旁，
依次从左到右，保持各自面孔、发型与衣着；取图 4 的布局与午后光线
```
